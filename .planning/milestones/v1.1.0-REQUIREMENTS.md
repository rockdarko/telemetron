## v1.1.0 Requirements — All Complete

### Storage migration (STORE)

- [x] **STORE-01** *(Phase 8-01)*: Operator runs the playbook and Garage (`dxflrs/garage:v2.3.0`) is running on the `telemetron` Docker bridge with S3 API on `:3900`, admin on `:3903`, single-node layout assigned + applied, and all 5 buckets bootstrapped with a key that has read/write/owner permissions. **Outcome — VALIDATED.** Live state: `garage layout show` reports applied single-node layout; `garage bucket list` shows all 5 buckets (loki-chunks, tempo-traces, mimir-blocks, mimir-ruler, mimir-alerts).
- [x] **STORE-02** *(Phase 8-02)*: Loki/Tempo/Mimir S3 configs retargeted from `minio:9000` to `garage:3900`; all three backends successfully read and write objects through Garage's S3 API. Loki uses `object_store: aws` (G-6 mitigation). Credential vars renamed from `minio_root_*` to `garage_*`. **Outcome — VALIDATED.** Live Grafana `/api/datasources/proxy/uid/{loki,tempo,mimir}/health` probes all return success on the Garage backend.
- [x] **STORE-03** *(Phase 8-03)*: `roles/minio/` directory, `minio/mc` image references, and all MinIO-specific vars removed; `playbooks/deploy_docker.yml` shows `garage` in the storage slot; documentation cascade complete (architecture, README, inventory, roles/README, CLAUDE.md). **Outcome — VALIDATED.** `grep -rl 'minio' roles/ playbooks/ inventory/example-homelab/` returns only inline migration comments; `docker ps` on leviathan shows no minio container post-cleanup.

### Backend config regressions (CONFIG)

- [x] **CONFIG-01** *(Phase 7-01)*: Mimir retention enforced — `limits.compactor_blocks_retention_period` wired in `mimir.yaml.j2` with operator-configured value (default `30d` via `mimir_compactor_blocks_retention_period`). **Outcome — VALIDATED.** Live `mimir.yaml` in-container renders the var under `limits:`; blocks older than 30d will be compacted away on the next compactor cycle.
- [x] **CONFIG-02** *(Phase 7-01)*: Tempo orphan var `tempo_compactor_block_ranges_period` re-wired to `compactor.compaction.compaction_window` in `tempo.yaml.j2` (default `1h`). **Outcome — VALIDATED.** `compaction_window` rendered under `compactor.compaction:`; orphan key gone.

### Ingest pipeline fixes (INGEST)

- [x] **INGEST-01** *(Phase 7-01)*: Fluent Bit logs without embedded timestamps receive ingest-time `@timestamp` fallback via Lua function in `enrich.lua`. **Outcome — VALIDATED.** `set_ingest_timestamp` helper added at 5 cache-shape call sites + 1 definition; nil-or-empty guard ensures source timestamps are never overwritten. Disabled FB-3 `[FILTER] modify` block removed.
- [x] **INGEST-02** *(Phase 9-01)*: Loki labels unified on `service_name` — `enrich.lua` emits `record["service_name"]` instead of `record["service"]`; doc cascade through defaults D-47 comment + fluentbit README + nfsd README; 7 curated dashboards verified clean. **Outcome — VALIDATED.** Live Loki labels: `["host", "job", "service_name"]`; legacy `service` label empty.
- [x] **INGEST-03** *(Phase 9-02)*: OTel Collector `transform` processor strips `service.namespace` resource attribute before `otlphttp/loki` exporter (upstream #32497 mitigation). **Outcome — VALIDATED.** Modern path-qualified OTTL (`delete_key(resource.attributes, "service.namespace")`) active on logs pipeline only; traces + metrics pipelines byte-identical pre/post.

### Operational (OPS)

- [x] **OPS-01** *(Phase 8-02)*: Garage self-metrics at `:3903/metrics` scraped by Prometheus with bearer-auth (`metrics_token`). **Outcome — VALIDATED.** First Prometheus job using `authorization.credentials` block (D-115); Garage S3 request counts, object counts, and storage usage are now queryable in Grafana.
