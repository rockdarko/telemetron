**File: `playbooks/smoke_test.yml`**

```yaml
---
# playbooks/smoke_test.yml
# Telemetron M1 acceptance smoke test (OPS-07).
#
# Pushes a synthetic OTLP log + metric + trace to the OTel Collector and
# asserts visibility in Grafana via datasource-proxy queries within a
# strict 60-second budget per assertion (retries: 12 / delay: 5).
#
# Usage:
#   ansible-playbook -i inventory/example-homelab playbooks/smoke_test.yml \
#                    --ask-vault-pass
#
# Targeted single-signal smoke:
#   ansible-playbook ... --tags log
#   ansible-playbook ... --tags metric
#   ansible-playbook ... --tags trace
#
# Prerequisites:
#   - playbooks/deploy_docker.yml has run to convergence on the target host.
#   - OTel Collector :4318 is reachable on localhost (host-published per
#     opentelemetry_publish_otlp default true).
#   - Grafana container (telemetron-grafana) is healthy with all four
#     datasource UIDs provisioned (loki, prometheus, mimir, tempo).
#
# Independent of deploy: this playbook reads secrets.yml directly via
# vars_files so it does not depend on a prior playbook setting variables.

- name: Telemetron -- M1 acceptance smoke test
  hosts: telemetron
  gather_facts: true
  become: false

  collections:
    - community.docker

  vars_files:
    # Pitfall 5: use inventory_dir-relative path so the playbook works
    # regardless of the operator's current working directory.
    - "{{ inventory_dir }}/group_vars/all/secrets.yml"

  vars:
    # Per-run hex IDs. lookup('password', '/dev/null') generates fresh
    # values on every invocation without writing to disk (RESEARCH C4).
    smoke_trace_id: "{{ lookup('ansible.builtin.password', '/dev/null length=32 chars=hexdigits') | lower }}"
    smoke_span_id:  "{{ lookup('ansible.builtin.password', '/dev/null length=16 chars=hexdigits') | lower }}"
    # Run id = Unix epoch -- per-run unique without an extra lookup. The
    # log query in the asserter filters by the literal marker, not by
    # run_id, so back-to-back runs in the same second still distinguish
    # by trace_id and metric label value.
    smoke_run_id:   "{{ ansible_date_time.epoch }}"

    # OTel Collector endpoint (default port 4318 OTLP/HTTP).
    otel_host: localhost
    otel_otlp_http_port: 4318

    # Grafana endpoint (reuse Phase 5 defaults inline to avoid pulling
    # the role's vars into a non-role context).
    grafana_container_name: telemetron-grafana
    grafana_admin_user: admin
    grafana_http_port: 3000

    # Retry budget = 12 * 5s = 60 seconds (D-99 / OPS-07 ROADMAP SC3).
    smoke_assert_retries: 12
    smoke_assert_delay: 5

  tasks:

    # =====================================================================
    # PRODUCERS (3)
    # =====================================================================

    - name: "Smoke producer -- push synthetic log via OTLP/HTTP"
      ansible.builtin.uri:
        url: "http://{{ otel_host }}:{{ otel_otlp_http_port }}/v1/logs"
        method: POST
        body_format: json
        headers:
          Content-Type: "application/json"
        body: "{{ lookup('template', 'smoke_test/templates/log.json.j2') | from_json }}"
        status_code: 200
      register: smoke_push_log
      tags:
        - log

    - name: "Smoke producer -- push synthetic metric via OTLP/HTTP"
      ansible.builtin.uri:
        url: "http://{{ otel_host }}:{{ otel_otlp_http_port }}/v1/metrics"
        method: POST
        body_format: json
        headers:
          Content-Type: "application/json"
        body: "{{ lookup('template', 'smoke_test/templates/metric.json.j2') | from_json }}"
        status_code: 200
      register: smoke_push_metric
      tags:
        - metric

    - name: "Smoke producer -- push synthetic trace via OTLP/HTTP"
      ansible.builtin.uri:
        url: "http://{{ otel_host }}:{{ otel_otlp_http_port }}/v1/traces"
        method: POST
        body_format: json
        headers:
          Content-Type: "application/json"
        body: "{{ lookup('template', 'smoke_test/templates/trace.json.j2') | from_json }}"
        status_code: 200
      register: smoke_push_trace
      tags:
        - trace

    # =====================================================================
    # ASSERTERS (4) -- Loki, Prometheus, Mimir, Tempo via Grafana proxy.
    # =====================================================================
    # Pattern mirrors roles/grafana/tasks/verify.yml exactly (proven on
    # leviathan 2026-05-19): docker_container_exec inside telemetron-grafana
    # + curl -fsS to localhost:3000 + retries:N / delay:N / until: succeeded.
    # 60-second budget = 12 * 5s.

    - name: "Smoke assert -- Loki received smoke log"
      community.docker.docker_container_exec:
        container: "{{ grafana_container_name }}"
        argv:
          - /bin/sh
          - -c
          - |
            set -e
            BODY=$(curl -fsS -u {{ grafana_admin_user }}:{{ grafana_admin_password }} \
              'http://localhost:{{ grafana_http_port }}/api/datasources/proxy/uid/loki/loki/api/v1/query?query=%7Bservice_name%3D%22telemetron-smoke%22%7D+%7C%3D+%22telemetron-smoke-test%22')
            echo "$BODY" | grep -q '"status":"success"' || { echo "loki status not success: $BODY"; exit 1; }
            echo "$BODY" | grep -q '"result":\[{' || { echo "loki result empty: $BODY"; exit 1; }
            echo "loki_smoke_ok"
      register: smoke_assert_loki
      retries: "{{ smoke_assert_retries }}"
      delay: "{{ smoke_assert_delay }}"
      until: smoke_assert_loki is succeeded
      changed_when: false
      failed_when: smoke_assert_loki is failed and smoke_assert_loki.attempts | default(0) >= smoke_assert_retries
      tags:
        - log

    - name: "Smoke assert -- Prometheus received smoke metric"
      community.docker.docker_container_exec:

# Telemetron smoke test

Acceptance smoke test for the Telemetron M1 data plane. Pushes a synthetic
log + metric + trace through the OTel Collector and asserts visibility in

## What it proves

3. Prometheus scrapes the metric from the OTel Collector's `prometheus` exporter.

5. Tempo receives the trace and makes it queryable by `traceId`.
6. Grafana's four datasource UIDs (`loki`, `prometheus`, `mimir`, `tempo`) all resolve.

If all 4 assertions pass, the data plane is end-to-end healthy.

## Prerequisites

- `playbooks/deploy_docker.yml` has run to convergence on the target host.
- `grafana_admin_password` is set in `inventory/<env>/group_vars/all/secrets.yml`.

## Run

Full smoke (all three signals):
```bash
ansible-playbook -i inventory/example-homelab playbooks/smoke_test.yml \
  --ask-vault-pass

Single signal (debug a specific data path):

ansible-playbook ... playbooks/smoke_test.yml --tags metric

```

## Budget

Each assertion task retries 12 times with 5-second delays -- 60 seconds
total per signal. The smoke test fails LOUDLY (non-zero playbook exit) if

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| Producer task fails with `Connection refused` on `:4318` | OTel Collector not running, or OTLP/HTTP receiver disabled | `docker ps -f name=telemetron-opentelemetry`; check `opentelemetry_publish_otlp` is `true` |
| Loki asserter exhausts retries | OTel Collector failing to forward logs to Loki, OR Loki ingester not flushing | Check `docker logs telemetron-opentelemetry` for export errors; check `docker logs telemetron-loki` for ingester errors |
| Prometheus asserter passes, Mimir asserter fails | Prometheus -> Mimir remote_write broken | Check `curl http://localhost:9090/api/v1/alertmanagers` and Prometheus's `remote_storage_*` metrics |
| Tempo asserter exhausts retries with 404 | Trace stuck in WAL or OTel Collector trace export failing | Check `docker logs telemetron-tempo` for ingester errors; verify OTel Collector's trace pipeline is healthy |
| Mimir asserter fails with 404 on URL | Mimir datasource URL path mismatch | Compare path in playbook (`/api/datasources/proxy/uid/mimir/api/v1/query`) with `roles/grafana/templates/datasources.yml.j2` |
