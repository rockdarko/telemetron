NOT fall back to the panel-level datasource for target-level mismatches --
those 51 panel-target queries error at runtime.

Read carefully: 05-04 hypothesised this issue (see 05-VERIFICATION.md "WARNING:
51 timeseries panels reference upstream org UIDs ... runtime behavior requires
UAT") and UAT confirmed the worst-case branch: Grafana errors, no fallback.

the walker (`walk()` in lines 126-140) recurses through `dict.values()` which
DOES naturally visit `targets[*].datasource` -- so the walker is already correct.
The only reason 05-04 didn't catch the 51 target-level upstream UIDs is that
the `uid_refs` map for tempo-operational.json only listed `$ds` and `$logsds`
template-var refs, NOT the 4 upstream hardcoded org UIDs that appear directly
in targets[*].datasource.uid as literal strings.

add 4 new keys mapping the upstream org UIDs to `{type:prometheus, uid:prometheus}`.

The walker (lines 126-140) is already correct:

```python
def walk(obj):
    if isinstance(obj, dict):
        if "datasource" in obj and isinstance(obj["datasource"], dict):
            uid = obj["datasource"].get("uid")
            if uid in uid_refs:
                obj["datasource"] = dict(uid_refs[uid])
        # Older format: datasource is a string
        if "datasource" in obj and isinstance(obj["datasource"], str):
            if obj["datasource"] in uid_refs:
                obj["datasource"] = dict(uid_refs[obj["datasource"]])
        for v in obj.values():
            walk(v)
    elif isinstance(obj, list):
        for v in obj:
            walk(v)
```

Note `for v in obj.values(): walk(v)` -- this recurses into ALL values of every
dict, which includes the `targets` list of every panel. Each item in `targets`
is a dict that may have a `datasource` key. The walker handles them. The only
reason 05-04 missed the upstream UIDs is they weren't in the uid_refs map.

The comment "Walk panels (and nested rows.panels) substituting datasource.uid"
at line 125 is misleading -- the walker visits everything. Update comment to:
"Walk all nested datasource refs (panels, rows.panels, panels[*].targets,
templating, anything else with a `datasource` key) and substitute uid via uid_refs map."
