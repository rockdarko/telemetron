<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → Ansible | `--ask-vault-pass` for vault secrets (Alertmanager doesn't currently consume vault secrets but the playbook pattern requires it) |
| Ansible → Docker daemon | `become: true` for `docker stop/start` and host `_data/` access |
| Docker volume `_data/` ↔ tarball | nflog + silences protobuf files (or empty state) written to mode-0600 tarball |
| Restore source tarball → volume `_data/` | Wipe + untar replaces silence/nflog state irreversibly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05-01 | Tampering | Tarball corruption | mitigate | `tar --zstd -tf` integrity check BEFORE wipe |
| T-13-05-02 | Denial of service | Restore wipes silences/nflog on misfire | mitigate | `backup_restore_confirm=true` fail-fast + integrity check |
| T-13-05-03 | Information disclosure | nflog protobuf may reveal recipient addresses for operators using real receivers | mitigate | Mode 0600 tarball + 0700 dest dir. Default Telemetron config uses `null` receiver — no recipient data. Encryption at rest deferred. |
| T-13-05-04 | Information disclosure | WARN msg echoing nflog content | mitigate | WARN names `{{ alertmanager_data_volume }}` only — no `tar tf` listing |
| T-13-05-05 | Spoofing | Stale nflog re-fires alerts on restore (AP-2) | accept | Documented in header + Phase 15 per-role README. Operators wired to real receivers see post-restore re-notification window for ongoing alerts. No code-level guard (the alternative — selective state restore — is out of v1.3.0 scope per FEATURES.md anti-features). |
| T-13-05-06 | Tampering | Empty-data backup masquerading as fresh tarball | accept | The empty-state edge case is the documented Alertmanager behavior. Backup task's stat-guard logs an informational debug; restore handles empty tarballs cleanly via Alertmanager's first-state-write file creation (AP-1). |
| T-13-05-07 | Tampering | XP-1 `state: stopped` strips volume specs | mitigate | Explicit `ansible.builtin.command: docker stop` + poll. AN-1 enforcement. |
| T-13-05-08 | Elevation of privilege | `become: true` on root-owned paths | accept | Required by Docker host filesystem permissions |
| T-13-05-SC | Tampering | npm/pip/cargo installs | n/a | Only `zstd` via OS package manager. No npm/pip/cargo audit needed. |
</threat_model>
