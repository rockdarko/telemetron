## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → Ansible | `--ask-vault-pass` for vault-encrypted `grafana_admin_password` |
| Ansible → Docker daemon | `become: true` for `docker stop`/`docker start` and host `_data/` access |
| Docker volume `_data/` ↔ tarball | grafana.db + plugins/ + csv/ written to mode-0600 tarball |
| Restore source tarball → volume `_data/` | Wipe + untar replaces SQLite + plugins irreversibly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-04-01 | Tampering | Tarball corruption | mitigate | `tar --zstd -tf` integrity check BEFORE wipe |
| T-13-04-02 | Denial of service | Restore wipes operator dashboards on misfire | mitigate | `backup_restore_confirm=true` fail-fast gate + integrity check (two layers) |
| T-13-04-03 | Information disclosure | grafana.db SQLite contains admin password hash + user accounts | mitigate | Mode 0600 tarball + 0700 dest dir. Encryption at rest deferred (FEATURES.md anti-feature). |
| T-13-04-04 | Information disclosure | WARN msg echoing dashboard contents | mitigate | WARN names `{{ grafana_data_volume }}` only — no `tar tf` listing in WARN |
| T-13-04-05 | Spoofing | Post-restore admin password silently reverts to backup-time value (GR-4) | mitigate | Header documentation of `grafana-cli admin reset-admin-password` workaround. Phase 15 docs surface in per-role README. No code-level guard (Grafana's first-boot-only env var behavior is the upstream contract). |
| T-13-04-06 | Tampering | Operator-installed plugins lost if backup excludes `plugins/` (GR-2) | mitigate | Tar entire `_data/` tree, NOT just `grafana.db`. Acceptance criterion enforces no `--exclude` flags on tar. |
| T-13-04-07 | Tampering | XP-1 `state: stopped` strips volume specs | mitigate | Explicit `ansible.builtin.command: docker stop` + poll. AN-1 enforcement. |
| T-13-04-08 | Elevation of privilege | `become: true` on root-owned paths | accept | Required by Docker host filesystem permissions |
| T-13-04-SC | Tampering | npm/pip/cargo installs | n/a | Only `zstd` via OS package manager. No npm/pip/cargo audit needed. |
</threat_model>
